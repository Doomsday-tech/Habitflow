# HabitFlow

HabitFlow is a simple habit tracking application that helps users build consistency by managing daily habits. Users can create habits, track their progress, and mark completed tasks to stay accountable and productive.

## Features

- Create and manage daily habits
- Mark habits as completed
- Track progress
- Data persistence using Local Storage
- Simple and responsive interface

## Tech Stack

- React
- JavaScript
- CSS
- Local Storage

## Installation

```bash
npm install
npm run dev
```
